# FitBros

## التحديث
- شريط التنقل ثابت أعلى الشاشة مع انتقالات ناعمة بين الصفحات.
- جلسة الدخول تبقى محفوظة على نفس الجهاز والمتصفح حتى تضغط خروج.
- لا يتكرر سجل النوم لنفس المستخدم والتاريخ؛ حفظ نوم جديد في اليوم نفسه يستبدل التسجيل السابق.
- إضافة صفحة مستقلة لسجل الجري والتمارين، مع عرض تسجيلات الحساب الحالي فقط.
- تسجيل الجري وتسجيل التمرين في بطاقتين جنبًا إلى جنب على الموبايل.
- اسم قسم الأكل أصبح «تسجيل الأكل والشرب».

## النشر
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages بجانب ملف `icon.png` الخاص بك. لا يوجد ملف أيقونة ضمن هذه الحزمة؛ اترك صورتك `icon.png` كما هي.

## ملاحظة البيانات
تُحفظ البيانات في `localStorage` على الجهاز الحالي فقط. لا توجد مزامنة بين الأجهزة. تسجيل الدخول تجريبي بكلمة مرور ثابتة وليس نظام حسابات آمنًا.
