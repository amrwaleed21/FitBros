# FitBros — نسخة محسّنة

## الملفات
- `index.html`: واجهة الموقع.
- `style.css`: التصميم.
- `app.js`: تسجيل الدخول والسجلات والجدول والتحديات.
- `foods.json`: قائمة الأطعمة والقيم الغذائية التقديرية.
- `icon.png`: أيقونة افتراضية؛ يمكنك استبدالها بأيقونتك مع إبقاء الاسم نفسه.

## تحديث GitHub Pages من الموبايل
1. فك ضغط `FitBros-Updated.zip`.
2. افتح مستودع GitHub الخاص بك ثم اضغط **Add file → Upload files**.
3. ارفع محتويات المجلد مباشرة إلى جذر المستودع، وليس ملف ZIP نفسه.
4. وافق على استبدال الملفات القديمة ثم اضغط **Commit changes**.
5. انتظر اكتمال النشر، ثم افتح الموقع واعمل تحديثًا قويًا/امسح كاش المتصفح إذا بقي التصميم القديم.

## ملاحظات مهمة
- الجري والتمارين والأكل والنوم والجدول يسجلها الحساب الذي دخلت به فقط؛ لا يوجد اختيار لتسجيل نشاط لصاحب الحساب الآخر. صفحة السجل تعرض جريات عمرو وزياد معًا، ويمكن اختيار تاريخ محدد.
- الجدول يظهر في مربعات حسب أيام الأسبوع. عند إكمال نشاط من الجدول يُضاف إلى سجل التمارين/الجري للحساب الحالي.
- في تسجيل الأكل، اكتب الجرامات أو اتركها فارغة واستخدم عدد الحصص/القطع. القيم الغذائية تقديرية.
- هذه نسخة static: البيانات محفوظة في localStorage على المتصفح الحالي فقط. لن تنتقل تلقائيًا بين موبايل عمرو وموبايل زياد من دون قاعدة بيانات أونلاين.
- تسجيل الدخول بكلمة مرور تجريبية `12345` فقط، وليس نظام حماية آمنًا للاستخدام العام.
