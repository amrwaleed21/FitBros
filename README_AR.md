# FitBros — النسخة المبسطة

## الملفات
ارفع كل الملفات دي مباشرة في جذر مستودع GitHub: `index.html`, `style.css`, `app.js`, `foods.json`.

## تفعيل GitHub Pages
Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/(root)` → Save. استنى النشر وافتح الرابط الظاهر في Pages.

## الدخول
اختار Amr أو Ziad، وكلمة المرور التجريبية لكليهما `12345`. خانة كلمة المرور مخفية. غيّر كلمة المرور في `app.js` عند البحث عن `12345` لو عايز.

## مميزات النسخة
- واجهة مختصرة: الرئيسية، الأكل والشرب، التمرين والجري، أنا وصاحبي، النوم والتحديات.
- قاعدة أصناف غذائية ومشروبات بقيم تقديرية للسعرات والبروتين والكربوهيدرات والدهون والألياف، قابلة للبحث وتغيير عدد الحصص.
- تسجيل الجري لأي من Amr أو Ziad في نفس القسم مع مقارنة إجمالي المسافات.
- نقاط، مياه، تمارين، سجل أكل، نوم وتحديات فرعية.

## مهم جدًا بخصوص مشاركة البيانات
هذه نسخة تجريبية تحفظ البيانات في `localStorage` على نفس المتصفح والجهاز فقط. لن تظهر تسجيلات Amr تلقائيًا على موبايل Ziad. لمزامنة حقيقية بين موبايلين، يلزم إعداد قاعدة بيانات أونلاين مثل Supabase وربطها بالموقع. كلمات المرور الحالية تجريبية وليست نظام حسابات آمنًا.

القيم الغذائية تقريبية وليست بديلًا عن ملصق المنتج أو قاعدة بيانات غذائية متخصصة.
