# FitBros — النسخة المطورة

## رفع النسخة على GitHub Pages
1. فك ضغط `FitBros-Updated.zip` على جهازك.
2. افتح مستودع GitHub الخاص بك وارفع **محتويات المجلد** إلى جذر المستودع، واستبدل الملفات القديمة.
3. ارفع `index.html`, `app.js`, `style.css`, `foods.json` و`README_AR.md`.
4. ضع الصورة التي تريدها للأيقونة باسم `icon.png` في نفس مكان `index.html`. الموقع يستخدمها تلقائيًا.
5. افتح Settings → Pages، ثم Source: Deploy from a branch، واختَر `main` و`/(root)` ثم Save.

## مميزات
- ملف شخصي لكل من عمرو وزياد: وزن وطول وسن وهدف ونشاط، مع تقدير السعرات والمياه.
- أطعمة ومشروبات قابلة للبحث، وتقدير المغذيات حسب الكمية المدخلة بالجرام/مل.
- تسجيل جري ورياضة فردية أو «إحنا الاتنين»، مع تاريخ وسجل طويل الأمد.
- جدول أسبوعي مستمر قابل للإضافة والحذف، وإكمال النشاط يسجله في سجل التمارين.
- تحديات يومية وأسبوعية تتغير حسب التاريخ.
- واجهة ملونة بألوان خفيفة؛ المياه باللون الأزرق.

## ملاحظات مهمة
- هذه نسخة ويب تجريبية، تخزّن البيانات في `localStorage` على نفس المتصفح والجهاز فقط؛ لا تتزامن تلقائيًا بين هاتف عمرو وهاتف زياد. للمزامنة الحقيقية يلزم ربط قاعدة بيانات أونلاين مثل Supabase.
- كلمة المرور التجريبية الحالية للحسابين هي `12345`، وهي موجودة في كود الواجهة وليست وسيلة حماية آمنة.
- تقديرات الطعام واحتياج السعرات والمياه تقريبية، وليست نصيحة طبية أو تغذوية. انتبه بشكل خاص إذا كان المستخدم أقل من 18 سنة.
