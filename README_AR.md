# FitBros — النسخة المعدلة

## الملفات
- `index.html`: التطبيق الأساسي وصفحاته الداخلية.
- `settings.html`: صفحة إعدادات مستقلة فعليًا عن `index.html`.
- `settings.js`: تحميل إعدادات الحساب وحفظها ومزامنتها وإدارة إعادة الضبط.
- `app.js`: منطق التطبيق الأساسي وتحديث لوحة الرئيسية.
- `style.css`: التصميم المتجاوب للصفحات.
- `supabase-config.js`: إعدادات Supabase العامة المخصصة للمتصفح.
- `foods.json`: قاعدة أصناف الطعام.
- `SUPABASE_SETUP.sql`: مرجع إعداد قاعدة البيانات الحالي.

## ما تم تغييره
1. فصل إعدادات الحساب إلى ملف HTML مستقل، وربط زر الإعدادات به.
2. نقل تعديل بيانات الجسم وإعادة ضبط تسجيلات اليوم وإعادة ضبط الحساب إلى صفحة الإعدادات المستقلة.
3. تعديل تحديث الرئيسية بحيث لا يعتمد نجاح رسم كل أقسام التطبيق على نجاح قسم آخر؛ يتم تحديث احتياجات السعرات والمياه بصورة مستقلة، مع تحديث إضافي بعد ظهور الشاشة.
4. إعادة تحديث الرئيسية عند استعادة التبويب أو الرجوع للتطبيق.
5. الإبقاء على إعدادات جلسة Supabase الحالية دون تغيير اسم مفتاح الجلسة.
6. لم يتم تغيير منطق إضافة المياه في هذه النسخة بناءً على طلب المستخدم عدم إعادة تعديل الجزء الذي تم إصلاحه.

## النشر
ارفع جميع الملفات معًا إلى نفس مجلد GitHub Pages، ولا ترفع `index.html` وحده. بعد الرفع افتح `index.html` ثم جرّب تسجيل الدخول، وتأكد من أن `settings.html` موجود بجانبه.

## ملاحظة اختبار
تم التحقق من صياغة JavaScript (`node --check`) وعدم وجود معرّفات HTML مكررة أو مراجع عناصر ناقصة في الصفحة الأساسية. لم يتم إجراء اختبار حيّ باستخدام حساب Supabase حقيقي من داخل متصفح المستخدم، لذلك يجب التحقق من المزامنة بعد النشر.
