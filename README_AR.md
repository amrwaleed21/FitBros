# FitBros

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub الذي ينشر الموقع.
2. اترك ملف `icon.png` الذي رفعته أنت في جذر المستودع بجانب `index.html` و`style.css` و`app.js` و`foods.json`؛ هذا الأرشيف لا يستبدل أيقونتك.
3. من Settings → Pages اختر `Deploy from a branch` ثم `main` و`/(root)`.
4. انتظر انتهاء النشر وافتح الموقع في نافذة خاصة إذا ظهرت نسخة قديمة.

## ملاحظات
- تسجيل الدخول تجريبي بكلمة مرور مشتركة داخل الواجهة، وليس نظام حسابات آمنًا.
- البيانات محفوظة في LocalStorage على الجهاز والمتصفح الحالي، ولا تتزامن بين جهازين.
- الأرقام الغذائية واحتياج السعرات والمياه وتقدير حرق النشاط تقديرية وليست قياسًا طبيًا.
