# FitBros

مشروع ويب عربي RTL جاهز للرفع على GitHub Pages، بتصميم أسود وبرتقالي.

## تسجيل الدخول التجريبي
- Amr — كلمة السر `12345`
- Ziad — كلمة السر `12345`

## الصفحات والميزات
- الرئيسية ولوحة النقاط.
- سجل التمارين (مقاومة، جري، كاليستنكس، مشي، منزلي).
- الوجبات والمياه.
- سجل النوم.
- تحديات.
- عرض تقدم الحسابين.

## مهم قبل الاستخدام الحقيقي
هذه نسخة تجريبية بسيطة. تسجيل الدخول مكتوب داخل `app.js` والبيانات تُحفظ في `localStorage`، أي على نفس المتصفح والجهاز فقط. هذا ليس تسجيل دخول آمنًا، ولا يزامن البيانات بين هاتفين. لا تستخدمها لحفظ معلومات خاصة أو حساسة. لكي يرى Amr وZiad بيانات بعضهما على جهازين مختلفين، يجب ربط Supabase Authentication وقاعدة بيانات وسياسات RLS واختبارها. لا تضع `service_role` أو secret key في ملفات الواجهة.

## الرفع من الهاتف
1. أنشئ Repository جديدًا على GitHub باسم `fitbros`.
2. فك ضغط ZIP على الهاتف إن أمكن، ثم ارفع **الملفات الموجودة داخل مجلد FitBros-GitHub** إلى جذر المستودع، وليس ZIP نفسه.
3. افتح Settings → Pages.
4. اختر Deploy from a branch، ثم `main` والمجلد `/(root)`، واضغط Save.
5. انتظر رابط GitHub Pages وافتحه.

## تحويله إلى APK
انسخ رابط GitHub Pages المنشور إلى خانة Website URL في WebToApp. غالبًا يكون شكله `https://USERNAME.github.io/fitbros/`، مع استبدال USERNAME باسم حسابك.

## إعداد Supabase لاحقًا
`config.js` مجرد مكان لإعداد الرابط ومفتاح النشر مستقبلًا؛ النسخة الحالية لا تتصل بـ Supabase بعد.
